## 它是什么

- **完全离线**：大模型跑在你自己的 CPU 上，不联网、不上传、不调用任何云端接口
- **不用显卡**：普通办公本就能跑，4 核 CPU + 8GB 内存起步
- **开箱即用**：双击「启动」就能用，不用装 Python、不用敲命令行
- **带公文能力**：内置 20 个公文文种知识卡和 11 类确定性核稿规则（来自 [gongwen-ai](https://github.com/Xuxu9527-tommmm/gongwen-ai) 项目）
- **支持国产系统**：银河麒麟、统信 UOS 直接跑

它能做的事：公文起草与核稿、周报日报、通知请示、表格整理、材料润色、附件问答等，页面上可切换技能。

## 大模型：本仓库不含，需要自己下载

**为什么不含**：单个模型 1～5GB，且各家许可证不同，不适合放在代码仓库里。程序本身不依赖某个特定模型，任何 GGUF 格式的模型都能认。

### 推荐

| 模型 | 文件大小 | 内存建议 | 适合 |
|---|---|---|---|
| **Qwen3-4B-Instruct-2507**（Q4_K_M） | 约 2.4GB | 8GB | 日常公文、周报，速度与质量的平衡点，**首选** |
| DeepSeek-R1-Distill-Qwen-1.5B（Q4_K_M） | 约 1.1GB | 4GB | 老机器、快速草稿 |
| DeepSeek-R1-0528-Qwen3-8B（Q4_K_M） | 约 4.7GB | 12GB 以上 | 质量优先，速度慢一些 |

### 下载地址

到 HuggingFace 镜像站（国内直连）下载 GGUF 格式的 `Q4_K_M` 版本：

- Qwen3-4B：`hf-mirror.com/Qwen/Qwen3-4B-Instruct-2507-GGUF`
- DeepSeek 1.5B：`hf-mirror.com/unsloth/DeepSeek-R1-Distill-Qwen-1.5B-GGUF`
- DeepSeek 8B：`hf-mirror.com/unsloth/DeepSeek-R1-0528-Qwen3-8B-GGUF`

也可以用 ollama 下载后取其 gguf 文件（`ollama pull qwen3:4b`）。

### 放在哪里

下载到的 `.gguf` 文件放进项目目录下的 **`模型/`** 文件夹即可（没有就新建一个，名字就叫「模型」）。

- 可以放多个模型，程序按内存自动挑「装得下、又最好」的那个
- 想放别处：编辑 `config.txt`，在 `DIR=` 一行写上你的模型文件夹路径（如 `D:\models`）
- 启动参数不用背，`config.txt` 里每项都有中文注释，留空就是自动档

放好模型，双击「启动-Windows.bat」（Linux 跑 `启动-Linux.sh`，macOS 双击 `启动-Mac.command`），浏览器页面会自动打开。

## 激活（一机一码）

第一次启动时，启动窗口会显示一个 8 位**本机机器码**（形如 `CG7E-PNL4`）。

**本仓库已包含序列号生成器**（`发号器/序列号生成器.html`，浏览器直接打开）：

1. 把启动窗口显示的机器码粘贴进发号器
2. 点「生成」，得到一串序列号（形如 `BGS9-8YJA-3HF9-U6RP-WX`）
3. 粘回启动窗口回车，完成激活

一个机器码对应一个序列号；换电脑、重装系统后机器码会变，重新生成即可。激活文件在 `授权/` 文件夹里，删除它即可重新激活。

> **注意**：发号器算法与程序内校验完全一致，属于本项目作者主动公开——这意味着激活只是记录使用者的开关，不构成任何技术壁垒，也请勿将本项目用于商业授权销售。

## 能力边界（请务必读完）

- **做得稳的**：文种判断、结构骨架、格式硬伤、语气、版式——这些靠确定性规则，不靠模型
- **做不好的**：长文后半段结构会漂移；数字、人名、日期容易被模型编造，**必须人工核对**；不引用政策依据；地方习惯用语覆盖不全
- **明确不做的**：不判密级、不替代签发、不保证政策时效、不做事实核查

**安全边界**：离线解决的是「内容不外流」，不解决「能不能装」。涉密计算机、物理隔离的私密电脑**不建议使用**，装未审批软件本身违规；普通办公电脑个人日常使用，建议按单位规定报备。
