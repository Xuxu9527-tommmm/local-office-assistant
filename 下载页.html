为什么非要切成 3 个？ 资料库单个文件上限是 1 GB，整包 2.5 GB 传不上去，只能把模型切成三段分开装。

这是三个普通压缩包：没有安装程序、没有 bat 脚本、不用敲命令，也不用装 7-Zip。Windows 自带解压就够了。

02解压（三个都解到同一个文件夹）

  1. 硬盘上先建一个文件夹，比如 D:\办公助手。别放桌面，别放 C 盘根目录，路径别太深。
  2. 右键第 1 个包 →「全部解压」，目标填 D:\办公助手。
  3. 第 2、3 个照做，目标还是这个文件夹。提示「目标文件夹已存在，是否合并」点 是，提示覆盖点「全部」。
  4. 三个都解压完，D:\办公助手\本地办公助手_v1.5.0 里就是完整程序。
第一次启动会多等 1～2 分钟。它要把 3 个模型分片拼回一个完整文件，只做这一次，以后就快了。 黑窗口里会写「正在把模型分片拼成完整文件」，不是卡住，别关窗口。

03启动（看你的系统）

系统双击这个第一次的提示
Windows 10 / 11启动-Windows.bat可能弹「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」
macOS（Intel / M 系列）启动-Mac.command右键 →「打开」→ 再点一次「打开」
银河麒麟 / 统信 UOS启动-Linux.sh右键 →「属性」→ 勾上「允许作为程序执行」，再双击；或在终端里 bash 启动-Linux.sh
国产电脑说明：包里自带了运行环境，不需要系统装新版本 glibc，麒麟 V10、UOS 20 直接能跑。 兆芯、海光走 x86 引擎，飞腾、鲲鹏走 ARM 引擎，程序按 CPU 自动选。
龙芯（LoongArch）和申威（SW64）目前没有现成引擎，需要单独编，用之前先问我。
启动那个黑窗口不要关，关了就等于退出程序。用完直接关窗口。
第一次启动要序列号：黑窗口里显示 8 位机器码（形如 AB12-CD34），发给我换一串 BGS9-… 粘回去回车，以后不再问。

06装不上怎么办

现象怎么办
点下载没反应再点一次；或换 Edge / Chrome。文件页里点右上角下载图标。
提示「模型不完整：现在只有 N 个分片」还有包没解压。把剩下的一两个包也解压到程序所在的那个文件夹，提示「目标文件夹已存在」点「是」，覆盖点「全部」。
黑窗口里一堆 'xx' 不是内部或外部命令，最后说「没有找到模型文件」这是早期版本的启动脚本有毛病，模型其实已经解压好了。不用重下 1GB：下载 启动脚本_修正版（4 KB），解压后得到的 启动-Windows.bat 覆盖到程序文件夹里同名文件，再双击。
Windows 提示「已保护你的电脑」点「更多信息」→「仍要运行」。没做数字签名的启动脚本都会这样，不是病毒。
点启动输入序列号后，引擎窗口闪一下就没了新版启动脚本会自动换保守参数、再自动换包内备用引擎重试，一般不用管。还不行就双击 诊断-Windows.bat，看「退出码」一行：杀软拦截（把整个文件夹加白名单）、Win11「智能应用控制」拦截（设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 → 智能应用控制，关掉再启动）、缺 VC++ 运行库（按诊断提示装）。在压缩包里直接双击也会这样，先解压出来。
国产系统报 GLIBC 错误不该出现——包内已带运行环境。真碰到了，把报错整段发我，同时告诉我 CPU 型号和 ldd --version 第一行。
粘了一大段材料，提示「太长放不下」8G 电脑一次粘不下几万字。把材料存成文件拖进来，软件会自动分批处理，不受这个限制。
浏览器没自动打开手动开浏览器，地址栏输入 127.0.0.1:8080。
第一次启动停在「正在拼装模型」正常，2.4 GB 拼一次要几十秒到两分钟。硬盘灯在闪就是在干活。
