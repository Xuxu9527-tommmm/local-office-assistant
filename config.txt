# 本地办公助手 · 配置文件
#
# ★ 不用改这个文件！所有参数都会按你的电脑自动调好。
#   平时直接双击「启动」就行，这里保持全空即可。
#   下面每一项只有「你想强制指定」时才需要填，填了会覆盖自动档。
#
# MODEL = 强制使用某个模型（写相对路径或绝对路径）。
#         留空（推荐）：模型文件夹里有几个都没关系，
#                       软件会按你的内存自动挑「装得下、又最好」的那个，
#                       页面上不给选，避免选大了卡死。
# MODEL=

# DIR = 额外的模型文件夹，一行一个，可以写绝对路径。
#       比如 D:\models 或 /home/you/models，里面的 .gguf 会被自动找到。
# DIR=D:\models

# CTX = 上下文长度（一次能记住多少字）。留空 = 自动：
#       16G 及以上 → 16384；12～16G → 8192；8～12G → 3072；8G 以下 → 2048。
#       自动档已经按内存算好，不建议手改。
#       内存小还想更快的，可以往下调（2048 就够聊天用），但长文档分会更碎。
# CTX=

# THREADS = 用几个 CPU 线程。留空 = 自动（物理核数 - 1，最多 12）。
#           注意：这里说的是「物理核」，不是任务管理器里那种逻辑核。
#           线程数超过物理核，生成速度会暴跌（实测差 20 倍），不要乱填大。
#           风扇太响、电脑卡就调小到 4。
# THREADS=

# KVQ = 1 强制用最高压缩（q4_0），0 强制关闭压缩。留空 = 自动：
#       12G 以下 → q4_0（最省内存，几乎看不出质量差别）
#       12～16G → q8_0（省一半）
#       16G 以上 → 不压缩（最快）
#       极少数很老的 CPU 不支持，如果开了启动失败，填 0 即可。
# KVQ=
